# ระบบจัดการร้านคาเฟ่ (Cafe Management System) — เว็บแอปจริง

เว็บแอปฉบับสมบูรณ์: **Backend เขียนด้วย Java ล้วน + หน้าเว็บ HTML/CSS/JS**
เปิดผ่านเบราว์เซอร์ได้จริงที่ `http://localhost:8080`

**ไม่ต้องติดตั้ง Maven / Gradle / Spring / ไลบรารีใดๆ เพิ่มเติมทั้งสิ้น**
ใช้แค่ JDK ตัวเดียวก็รันได้ทันที เพราะ backend ใช้
`com.sun.net.httpserver.HttpServer` ที่มากับ JDK อยู่แล้ว

## ต้องมีอะไรก่อน

ต้องมี **JDK 17 ขึ้นไป** (ไม่ใช่แค่ JRE) ตรวจสอบด้วยคำสั่ง:
```bash
javac -version
```
ถ้าไม่มี ดาวน์โหลดได้ที่ https://adoptium.net (เลือก JDK เวอร์ชัน LTS ล่าสุด)

## วิธีรัน (ทำตามนี้ทีละบรรทัด)

เปิด Terminal / Command Prompt ที่โฟลเดอร์ `cafe-management-system` (โฟลเดอร์นี้ต้องมี
โฟลเดอร์ย่อยชื่อ `src` กับ `web` อยู่ข้างใน) แล้วรันตามลำดับ:

```bash
# 1) คอมไพล์ไฟล์ java ทั้งหมดไปไว้ในโฟลเดอร์ bin
javac src/com/cafe/model/*.java src/com/cafe/server/*.java -d bin

# 2) รันเซิร์ฟเวอร์
java -cp bin com.cafe.server.ApiServer
```

เมื่อเห็นข้อความ `เปิดเบราว์เซอร์ไปที่: http://localhost:8080` แสดงว่าเซิร์ฟเวอร์รันสำเร็จ
เปิดเบราว์เซอร์ (Chrome/Edge/Firefox) ไปที่ **http://localhost:8080** ได้เลย

กด `Ctrl + C` ที่ Terminal เพื่อหยุดเซิร์ฟเวอร์

> ⚠️ สำคัญ: ต้องรันคำสั่ง `java` จากโฟลเดอร์ `cafe-management-system` (ตำแหน่งที่มีโฟลเดอร์
> `web` อยู่ด้วย) ไม่ใช่จากข้างในโฟลเดอร์ `src` หรือ `bin` ไม่งั้นจะหาไฟล์หน้าเว็บไม่เจอ

│   │   ├── OrderHandler.java       API จัดการออเดอร์/ชำระเงิน

│   │   └── ReportHandler.java      API รายงานรายรับ-รายจ่าย
│   └── app/

## หน้าเว็บมีอะไรบ้าง (ตรงตาม Use Case Diagram)

| แท็บ | ครอบคลุม Use Case |
|---|---|
| **เมนู & สั่งซื้อ** | ดูเมนู, สั่งเครื่องดื่ม, จ่ายเงิน |
| **จองโต๊ะ** | จองโต๊ะ |
| **ติดตามออเดอร์** | ดูสถานะคำสั่งซื้อ |
| **สำหรับพนักงาน** → ออเดอร์ทั้งหมด | รับออเดอร์, จัดการคำสั่งซื้อ, คิดเงิน/รับเงิน |
| **สำหรับพนักงาน** → จัดการเมนู | จัดการเมนู, จัดการเครื่องดื่ม, จัดการของหวาน |
| **สำหรับพนักงาน** → จัดการการจอง | รับจองโต๊ะ, จัดการโต๊ะ |
| **สำหรับพนักงาน** → วัตถุดิบ | จัดการวัตถุดิบ |
| **สำหรับพนักงาน** → รายงาน | ดูรายงาน (ดูรายรับ/ดูรายจ่าย) |

## ★ วิธีเพิ่ม/แก้ไขเมนูเครื่องดื่ม-ของหวาน-ราคา (ไม่ต้องแก้โค้ดแล้ว!)

ตอนนี้ทำผ่านหน้าเว็บได้เลย ไม่ต้องมาแก้ไฟล์ `.java` อีกต่อไป:
1. เปิดเว็บ → แท็บ **"สำหรับพนักงาน"** → แท็บย่อย **"จัดการเมนู"**
2. กรอกฟอร์ม "เพิ่มเมนูใหม่" (ชื่อ, หมวดหมู่, ราคา, คำอธิบาย, อีโมจิ) แล้วกด "เพิ่มเมนู"
3. แก้ราคาเมนูเดิม หรือเปิด/ปิดขาย ได้จากรายการด้านล่างฟอร์มทันที

(ข้อมูลจะหายเมื่อปิดเซิร์ฟเวอร์ เพราะยังเก็บไว้ใน RAM ไม่ได้ต่อฐานข้อมูลถาวร ถ้าต้องการเก็บ
ข้อมูลถาวรข้ามการรีสตาร์ท บอกได้เลย ผมช่วยต่อฐานข้อมูล เช่น SQLite/MySQL ให้ได้)

## ถ้าอยากแก้ไอคอน/สี/หน้าตาเว็บ

แก้ที่ไฟล์ `web/style.css` (สี, ระยะห่าง) และ `web/index.html` (โครงหน้า) ได้เลย
ไม่ต้องคอมไพล์ใหม่ แค่รีเฟรชเบราว์เซอร์ (ไฟล์เว็บไม่ต้อง javac)
ส่วนถ้าแก้ไฟล์ `.java` ต้องรันคำสั่ง `javac` ใหม่ (ขั้นตอนที่ 1 ด้านบน) แล้วรัน `java` ใหม่

## ถ้าพอร์ต 8080 ถูกใช้งานอยู่แล้ว

แก้ตัวเลข `8080` ในบรรทัด `int port = ... : 8080;` ของไฟล์ `src/com/cafe/server/ApiServer.java`
เป็นพอร์ตอื่น เช่น `8081` แล้วคอมไพล์ใหม่

## ★★ วิธี Deploy ให้ได้ลิงก์ถาวร (เปิดจากเครื่องไหนก็ได้ ไม่ต้องเปิดคอมตัวเองทิ้งไว้) ★★

โปรเจกต์นี้มีไฟล์ `Dockerfile` เตรียมไว้ให้แล้ว ใช้สำหรับ deploy ขึ้น **Render.com**
(มีแผนฟรีให้ใช้) ทำตามขั้นตอนนี้:

### ขั้นที่ 1: อัปโหลดโค้ดขึ้น GitHub

1. สมัครบัญชีที่ https://github.com (ถ้ายังไม่มี)
2. กดปุ่ม **+** มุมขวาบน → **New repository**
3. ตั้งชื่อ เช่น `cafe-management-system` → เลือก **Public** → กด **Create repository**
4. ในหน้า repo ที่สร้างเสร็จ จะมีปุ่ม **uploading an existing file** (ลิงก์สีฟ้า) → กดเลย
5. **ลากทุกไฟล์/ทุกโฟลเดอร์**จากในโฟลเดอร์ `cafe-management-system` (ที่แตกจาก zip)
   ไปวางในหน้าเว็บนั้น (ลาก `src`, `web`, `Dockerfile`, `README.md`, `.gitignore` ทั้งหมด)
6. เลื่อนลงล่าง กด **Commit changes** เป็นอันเสร็จ — ตอนนี้โค้ดอยู่บน GitHub แล้ว

### ขั้นที่ 2: เชื่อม Render.com กับ GitHub แล้ว Deploy

1. สมัครที่ https://render.com (เลือก **Sign up with GitHub** จะได้เชื่อมกันอัตโนมัติ)
2. หลัง login แล้ว กด **New +** → **Web Service**
3. เลือก repo `cafe-management-system` ที่เพิ่งอัปโหลดไป → กด **Connect**
4. หน้าตั้งค่า:
   - **Name**: ตั้งชื่ออะไรก็ได้ เช่น `cafe-management-system` (ชื่อนี้จะไปอยู่ในลิงก์)
   - **Language / Runtime**: เลือก **Docker** (Render จะเจอ `Dockerfile` ที่เตรียมไว้ให้เองอัตโนมัติ)
   - **Instance Type**: เลือก **Free**
5. กด **Deploy Web Service** ที่ปุ่มด้านล่าง
6. รอสัก 2-5 นาที (จะเห็น log กำลังคอมไพล์ขึ้นเรื่อยๆ) จนสถานะขึ้นเป็น **Live** (จุดสีเขียว)
7. ด้านบนหน้าจอจะมีลิงก์ประมาณ `https://cafe-management-system-xxxx.onrender.com`
   **อันนี้แหละคือลิงก์ถาวร** ส่งให้อาจารย์เปิดได้เลย จากเครื่องไหน ที่ไหนก็ได้ในโลก 🎉

### ข้อควรรู้เกี่ยวกับแผนฟรีของ Render

- ถ้า**ไม่มีคนเข้าเว็บนานเกิน ~15 นาที** เซิร์ฟเวอร์จะ "หลับ" ไปเอง (ประหยัดทรัพยากร)
  พอมีคนเปิดลิงก์ครั้งแรกหลังจากนั้น **จะโหลดช้าประมาณ 30-50 วินาที** (รอบเดียว) แล้วหลังจากนั้นจะเร็วปกติ
  → แนะนำให้**เปิดลิงก์ทิ้งไว้ก่อนพรีเซนต์สัก 2-3 นาที** เพื่อ "ปลุก" เซิร์ฟเวอร์ล่วงหน้า กันเสียเวลาหน้างาน
- ข้อมูล (เมนูที่เพิ่ม/ออเดอร์) ยังคงเก็บในหน่วยความจำเหมือนเดิม ถ้าเซิร์ฟเวอร์รีสตาร์ท
  (เช่นตอนหลับแล้วตื่น หรือ deploy โค้ดใหม่) **ข้อมูลจะรีเซ็ตกลับเป็นเมนูตัวอย่างเริ่มต้น**
  ถ้าอยากเก็บถาวรข้ามการรีสตาร์ท ต้องต่อฐานข้อมูลจริงเพิ่ม (บอกได้ ผมช่วยต่อให้ได้)

### ถ้าแก้โค้ดแล้วอยากอัปเดตเว็บที่ deploy ไปแล้ว

กลับไปที่หน้า repo บน GitHub → อัปโหลดไฟล์ที่แก้ไขทับของเดิม (หรือลบ-เพิ่มใหม่) → commit
Render จะ deploy เวอร์ชันใหม่ให้อัตโนมัติภายในไม่กี่นาที ไม่ต้องกดอะไรที่ Render เพิ่มเอง

## ขั้นต่อไปที่ทำเพิ่มได้ (ถ้าต้องการ)

- **เก็บข้อมูลถาวร**: ต่อฐานข้อมูลจริง (SQLite ใช้ง่ายสุดสำหรับโปรเจกต์เดี่ยว, หรือ MySQL)
- **ระบบ login**: ตอนนี้ยังไม่มีการเข้าสู่ระบบ ทุกคนเห็นแท็บ "สำหรับพนักงาน" ได้หมด
  ถ้าต้องการแยกสิทธิ์ลูกค้า/พนักงานจริงจัง บอกได้เลย
- **อัปโหลดรูปเมนูจริง** แทนอีโมจิ
